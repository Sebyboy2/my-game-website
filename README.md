# GameHub Starter

A small StrongDog-style game portal starter built with plain HTML, CSS and JavaScript.

## Run it

Open `index.html` in a browser, or serve the folder with any static web server.

## Add a game

1. Create a folder under `games/`.
2. Put the game's HTML/assets there.
3. Add an entry to the `games` array in `script.js`.
4. Change the `url` to your game's entry page.
5. Replace the demo thumbnail/icon with your own artwork.

## Features

- Search
- Categories
- Favorites saved in localStorage
- Random game
- Individual game pages
- Responsive layout
- No framework required

Only host or embed games you have permission to distribute.
